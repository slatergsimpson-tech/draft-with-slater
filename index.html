Card ratings from real games

Out of the box, cards are rated by a built-in heuristic — a fine sparring partner, but it judges every card in a vacuum. Give the app real win-rate data and the bots draft the actual format, the pick ratings mean something, and the draft story stops guessing. Two ways:

Automatic: run node server/fetch-ratings.js SET once (say, BLB). It computes each card's games-in-hand win rate from 17Lands' public datasets (CC BY 4.0) and the app finds the result by itself whenever anyone drafts that set from this relay.

By hand: paste a ratings CSV or JSON below — any list with card names and win rates. It is remembered for the selected set, on this device.
